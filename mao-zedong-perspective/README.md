# 毛泽东 Perspective Skill

一个基于毛泽东思想和方法论的思维框架与决策启发工具。

## 项目概述

本项目以毛泽东（1893-1976）的思想方法论为核心，提取其独特的心智模型、决策启发式与表达方式，旨在为现代人提供分析问题、做出决策时的参考视角。毛泽东将马克思主义基本原理与中国革命具体实践相结合，形成了一套完整的认识论和方法论体系，至今仍具有深刻的启发意义。

## 核心功能

- **心智模型**：涵盖毛泽东六大核心思维框架（矛盾分析法、实践第一、群众路线、实事求是、战略上藐视战术上重视、独立自主）
- **决策启发式**：8条可操作的决策原则
- **表达DNA**：语言风格与表达特征分析
- **价值观体系**：核心价值观与反模式识别
- **质量检查**：自动化脚本确保Skill内容完整性

## 安装与使用

### 环境要求

- Python 3.6+

### 质量检查

```bash
python scripts/quality_check.py /path/to/mao-zedong-perspective
```

### 调研汇总

```bash
python scripts/merge_research.py /path/to/mao-zedong-perspective
```

### 使用方式

本Skill可作为思维顾问使用：

- 面对复杂问题时，思考"毛泽东会如何分析主要矛盾？"
- 决策前反思"是否进行了充分的调查研究？"
- 制定策略时，考虑"如何运用统一战线思维？"

# 苏东坡（苏轼）Perspective Skill

一个基于北宋文豪苏轼生平、诗词与思想的思维框架与决策启发工具。

## 项目概述

本项目以苏轼（1037-1101）的智慧为核心，提取其独特的心智模型、决策启发式与表达方式，旨在为现代人提供面对困境、做出决策时的参考视角。苏轼一生历经宦海沉浮，从黄州到惠州到儋州，始终保持旷达从容的人生态度，其思想至今仍具有深刻的启发意义。

## 核心功能

- **心智模型**：涵盖苏轼五大核心思维框架（旷达观、变与不变之辩、随缘自适、以诗为词、民本思想）
- **决策启发式**：7条可操作的决策原则
- **表达DNA**：语言风格与表达特征分析
- **价值观体系**：核心价值观与反模式识别
- **质量检查**：自动化脚本确保Skill内容完整性

## 安装与使用

### 环境要求

- Python 3.6+

### 质量检查

```bash
python scripts/quality_check.py /path/to/su-shi-perspective
```

### 调研汇总

```bash
python scripts/merge_research.py /path/to/su-shi-perspective
```

### 使用方式

本Skill可作为思维顾问使用：

- 面对困境时，思考"苏东坡会如何看待这件事？"
- 决策前，反思"这符合苏轼的哪些心智模型？"
- 写作表达时，参考其表达DNA与风格特征
